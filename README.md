# Lumbre

A concept site for a small Mexican kitchen on Santa Fe Drive in Denver. The menu, the cart, and the weekly specials are one system: Thursday margaritas, Tuesday street tacos, and a weekday afternoon board change the ticket based on the pickup or delivery time.

Lumbre is not a real restaurant. The phone number is fictional, the street is not a building, and the map opens the neighborhood. Orders stay on this device. Nothing is charged and nothing is sent to a kitchen. You pay at the window, or you pay the driver, which is the model the checkout is written for.

```bash
npm install
npm test
npm run dev
```
